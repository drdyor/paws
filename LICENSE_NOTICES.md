### Implementation Notes

The Paws project integrates Tinder-style swipe functionality using:
- **react-native-deck-swiper** library for card animations
- Custom TypeScript components adapted for pet profiles
- Original UI patterns reimagined for pet adoption/sales use case
- No direct code copying; inspired implementation with modern React Native patterns
